# Privacy Policy - NitroJam Clip Bot

Last updated: November 25, 2026

NitroJam Clip Bot is a personal tool operated by the streamer NitroJam. It is used only on the streamer's own computer and only with the streamer's own Google account. It is not offered to the public.

## What the app accesses

The app uses the YouTube Data API to upload short videos to the NitroJam YouTube channel and to read the channel name, so the streamer can confirm which channel is connected. It uses the Google Drive API only to create one folder and upload the finished short videos into the streamer's own Drive.

The app reads public Kick chat messages only to detect the !clip command. It keeps the username of the viewer who requested the clip so it can credit them in the video title.

## Storage and sharing

Login tokens and video files are stored only on the streamer's own computer and in the streamer's own YouTube channel and Google Drive. No data is sold, shared with third parties, or sent to any server operated by the app. Google user data is used only to provide the features described above.

## Your rights and removal

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the app folder from the computer removes all stored tokens and files.

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms). See also the Google Privacy Policy (https://policies.google.com/privacy).
